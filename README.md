# FloraVision 🌿

Responsive plant store frontend built using React, Vite, and Tailwind CSS.

## Features
- Responsive mobile design
- Modern UI
- Plant product sections
- Testimonials section
- Clean navigation bar
- Fast performance with Vite

## Tech Stack
- React
- Vite
- Tailwind CSS
